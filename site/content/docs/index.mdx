title: HooKit
description: Hooks with outcome-selected Pi Actions for Pi events.

HooKit is a hook engine for [Pi](https://github.com/earendil-works/pi), the
agent runtime you are reading this in. You define a **Hook**—a small policy
that subscribes to a Pi **Event** (a tool call, a finished turn, a settled
agent, a session change). When the Event happens, HooKit runs your Hook's
shell decision and may deliver one outcome-selected Pi **Action**, such as a
message, an interrupt, a shutdown, or a custom event.

Configuration lives in `.pi/hookit.json` as plain JSON. `/hooks` manages
installation, enablement, defaults, and Presets from inside Pi. Every policy
decision becomes observable in an Execution Report in the transcript.

Two ideas make HooKit useful:

- **You are in control of your tooling.** Policy is explicit and inspectable,
  not hidden inside the agent.
- **Feedback is tight.** Hooks subscribe at multiple points in a Pi lifecycle,
  so a policy can act before a tool runs, after a tool returns, at the end of
  a turn, and when the agent settles.

## Security in one sentence

Hook shells execute locally as trusted code with your Pi process permissions.
A timeout is not a sandbox. Treat repository Hooks like any third-party code
and review their Source before installation.
