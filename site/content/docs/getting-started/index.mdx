HooKit adds user-controlled policy Hooks to Pi Events. The Getting Started
section takes you from installation to one working Hook, then points you to
reusable policies.

1. **[Installation](/getting-started/installation)** installs HooKit globally
   or for one trusted Pi project and verifies that `/hooks` is available.
2. **[Write a hook](/getting-started/first-hook)** guides you through a
   dependency-free safety policy against a dummy `.env` file. Every
   step includes an expected result.
3. **[Explore the Hook library](/getting-started/library)** links to ready-made
   policies in the companion HooKit-rules repository.

Use **[Reference](/reference/configuration)** to look up the complete
configuration contract and runtime behavior. Use **[Concepts](/concepts/overview)**
to understand HooKit's evaluation, composition, and security models.

Hook shells execute locally as trusted code. Read the
**[security model](/concepts/security)** before installing or authoring policies
from an untrusted Source.
